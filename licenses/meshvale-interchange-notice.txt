Python wheels include Meshvale Geometry compiled code and record adapters (Apache-2.0),
tinyobjloader (MIT; see licenses/tinyobjloader.txt), nanobind (BSD-3-Clause)
and its robin-map dependency (MIT). Their notices accompany the distribution.

Statically linked Geometry position storage incorporates unmodified Eigen 3.4.1
Core code. Its MPL-2.0, Apache-2.0 and permissive notices accompany this
distribution in licenses/eigen-mpl2.txt, licenses/eigen-apache.txt and
licenses/eigen-notices.txt. Eigen source is available from
https://gitlab.com/libeigen/eigen/-/tree/3.4.1; no source modifications are made.

Optional native USD and FBX builds have separate dependency and notice closures.
Their source and enabled installation retain the notices identified in
THIRD_PARTY.md; the default OBJ Python binary does not include either SDK.

Private native parser implementation uses cgltf (MIT) and jsoncons
(Boost Software License 1.0). Their complete notices are included in
licenses/cgltf.txt and licenses/jsoncons.txt.
